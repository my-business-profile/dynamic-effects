# Dynamic Effects

An intentionally over-engineered front-end playground for showcasing high-class web VFX and interaction patterns.

## Included

- Three.js 3D particle field reacting to pointer movement
- GSAP + ScrollTrigger cinematic reveals and parallax
- Magnetic buttons
- 3D tilt cards
- Liquid-glass / grid / scanline / orbital visual treatments
- Interactive pointer-tracking lab
- Kinetic marquee
- Scramble typography
- Cursor glow + film grain
- Responsive mobile layout
- No build step required — open `index.html`

## Demo

Enable GitHub Pages for the `main` branch to publish it as a live static site.
